\label{sec:algorithm_principle}
An algorithm was developed for finding the static powers of the optics in HAM5/6 which gives perfect mode matching between the interferometer and the OMCs. There are three optics between the interferometer and an OMC which affect the mode matching between them, and two of these optics will have tuneable radii of curvature. Having the two tuneable optics separated by \ang{45} of Gouy phase will allow for the size of the beam's waist and the location of the beam's waist to be independently controlled.
\par
Consider the mode matching problems shown in Figure~\ref{fig:opticallayouts}. To visualise how this algorithm works, see Figure~\ref{fig:algorithmsketch}. The principle by which this algorithm works is: the continuum of modes after optic 1 and the continuum of modes just before optic 3 can be easily obtained since they must have a defined beam size, so they only vary in defocus. These two continua are propagated to optic 2, and then it is just a case of finding the optical power of a lens/mirror which will move a mode from one continuum to the other.
\par
The continua at optic 2 in Figure~\ref{fig:opticallayouts} and Figure~\ref{fig:algorithmsketch} do not necessarily need to have the shape that they are sketched with in Figure~\ref{fig:algorithmsketch}; however, if the blue-green and red-yellow continuum extend far enough, they will always wrap around. It is not guaranteed that every mode in the red-yellow can be reached from the blue-green continuum and vice versa. Since the mapping between the blue-green and red-yellow continuum is not one-to-one, two `branches' need to be considered. Both branches of the continua do not need to be analysed at the same time, but a better solution may be found by looking at different combinations of branches. This is useful in setting a limit on the size of the continuum you search.
\par
In our implementation of this algorithm, the `continua' were numerically implemented, thus they are discrete. Thus, when finding a mapping at optic two it is not guaranteed that a mode in the red-yellow continuum will have a corresponding mode of the same width in the blue-green continuum. Because of this granularity, if you were to plot optimal powers of optic 2 and optic 3 as a function of the power of optic 1, you would see jumps in the optimal lens choices. This is especially bad around the turning point of the continua since the modes defocus changes quickly while their size does not. 
\section{Method}
This section delineates the algorithm. See Figure~\ref{fig:opticallayouts} and Figure~\ref{fig:algorithmsketch} for the definitions of objects described in the following list.
\begin{enumerate}
	\item \textbf{Define the target mode at optic 3.} In Figure~\ref{fig:algorithmsketch}, this is mode l at optic three.
	\item \textbf{Define a set of modes which share the same beam size as the target mode at optic 3 but have varying radii of curvature.} In Figure~\ref{fig:algorithmsketch}, this is the red-yellow continuum at optic three.
	\item \textbf{Propagate the set of modes defined at optic 3 back to the optic 2.} In Figure~\ref{fig:algorithmsketch}, this is the red-yellow continuum at optic 2.
	\item \textbf{Define the initial beam parameter and propagate this to optic 1.} In Figure~\ref{fig:algorithmsketch}, this is mode i at optic one.
	\item \textbf{Define a set of modes that have the same beam size as the initial beam at optic 1 but differ in defocus.} In Figure~\ref{fig:algorithmsketch}, this is the blue-green continuum at optic one.
	\item \textbf{Propagate the modes defined at optic 1 to optic 2.} In Figure~\ref{fig:algorithmsketch}, this is the blue-green continuum at optic two.
	\item \textbf{Calculate the difference in optical power between mode i and a mode in the blue-green continuum (e.g. mode j).} In Figure~\ref{fig:algorithmsketch}, mode j represents just one possible mode in this continuum. Save this power.
	\item \textbf{Find a mode in the red-yellow continuum which is closest in size to mode j, call this mode k.} In Figure~\ref{fig:algorithmsketch}, there is another possible choice on the red-yellow continua, however only one of them needs to be considered.
	\item \textbf{Calculate the difference in optical power between mode j and mode k at optic 2.} Save this power.
	\item \textbf{Calculate the difference in optical power of mode k and the target mode at optic 3.} Save this power.
	\item \textbf{Calculate the Gouy phase separation of optic 2 and optic 3.}
	\item \textbf{Repeat for every mode in the blue-green continuum, or until a Gouy phase separation of 45\si{\degree} has been found.}
\end{enumerate}
\par
The number of modes that are considered and the range of modes in the continua should be tailored for the optical layout that is being considered. Our problem had metre scale spacings between optics and Rayleigh lengths. It was found that continua with a range of the order 1-10 dioptres were suitable. This does not mean that an adaptive optic would need this actuation range, rather it allowed for the static radii of curvature for each optic that gives optimal Gouy phase separation between the active mode matching elements to be found. Using this algorithm, we were able to rapidly develop many possible HAM6 layouts. This allows for more time to consider various engineering factors (suspension size and the like) and how to adapt the mirror strengths accordingly to accommodate for small changes in a tentative design.
